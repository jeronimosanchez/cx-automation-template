# docs/panels

Artefactos HTML de control — vistas visuales de archivos clave del proyecto. No son documentación ni código del sistema: son herramientas de trabajo para revisar y modificar artefactos en sesión con Claude Code.

## Cómo usarlos

Abre el panel en Claude Code (artifact URL) o directamente en el navegador. Para hacer cambios, describe qué quieres modificar — Claude aplica el cambio en el archivo fuente real y actualiza el panel.
